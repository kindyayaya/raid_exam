填寫規則

時間軸建議填整數秒（3、-4）；也接受文字 MM:SS。副本及階段可沿用上一列。單選／複選：選項欄留空即為簡易出題，直接填寫答案文字，複選以「｜」分隔；選項欄有內容則以原本的 1 起算編號填答（多項逗號分隔）。順序與走位題仍使用編號。共通答案與 MT～D4 欄擇一填寫，職位留空即不適用。題型：單選、複選、順序、點選走位、拖曳走位。走位題可引用已存在的唯一場景名稱；引用時選項可留空。拖曳起始 X/Y 可留空（預設 200、300）。未填題目敘述會使用預設句型；未填解析僅帶入答案提示，不會推測攻略。

舊版 Excel 若主工作表沒有題目 ID，預設仍會新增，請從新版重新匯出後修改。Excel 讀取「題庫」工作表（沒有則第一張）；不支援 .xls、加密檔案及公式。範本另有示範及說明工作表。

請保留匯出檔的題目 ID；未知 ID 會阻止匯入。更新以 Excel 主工作表為準，請使用最新匯出檔，避免覆蓋較新的修改。既有題目的獨立解析及適用的起始座標會保留，補充資料工作表不參與匯入。更新既有題目會保留圖片；目前 Excel 尚不支援圖片網址匯入匯出，請用 JSON 備份引用。
